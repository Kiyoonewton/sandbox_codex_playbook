# The text style you pick isn't reflected everywhere

## What you see

When I choose Pirate Speak, the button lights up as selected, so I can tell the app registered my choice. But the empty specimen box off to the side still announces the classic Lorem flavor, as though I'd never switched at all. It's confusing enough that I clicked the option again a couple of times to make sure it had actually taken.

## What correct looks like

Picking a flavor should update everything on screen that refers to it, so the specimen box names whichever style is currently highlighted rather than stubbornly showing the default one.
